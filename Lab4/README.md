# Lab 4 Authenticate with Firebase Contacts App

Ứng dụng Flutter Contacts App dùng Firebase Authentication và Cloud Firestore.

## Chức năng

- Email/Password login
- Google Sign-In
- Firestore CRUD contacts
- Search contacts
- Add/Update/Delete

## Cách chạy

```bash
flutter pub get
flutter run
```

## Lưu ý Firebase

- `google-services.json` nằm ở `android/app/google-services.json`
- Package name Android: `com.example.restaurant_app`
- Bật Authentication Email/Password
- Bật Google provider
- Bật Firestore Database
